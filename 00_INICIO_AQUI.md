| Problema | Solución |
|----------|----------|
| Port 4200 occupied | `npm start -- --port 4300` |
| Module not found | `npm install` |
| Styles not applying | `rm -rf .angular/cache && npm start` |
| Build error | `npm run build` para ver detalles |
